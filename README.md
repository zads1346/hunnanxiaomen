# 浑南校门

东北大学浑南校区东门的可编辑 Blender 场景，当前为 V4 照片参考迭代版。

这是艺术建模与结构练习，依据照片估算比例和细节，并非校方官方模型、实测测绘成果或施工资料。背面构造、尺寸、碑厚和部分雕饰采用近似处理，植栽、岗亭等环境也有简化。

## 下载与解压

模型采用 ZIP 分卷保存。请同时下载以下两个文件，并放在同一个文件夹，保持文件名不变：

- [NEU_Hunnan_East_Gate.z01](NEU_Hunnan_East_Gate.z01)
- [NEU_Hunnan_East_Gate.zip](NEU_Hunnan_East_Gate.zip)

使用支持分卷 ZIP 的 7-Zip 或 WinRAR 打开 **NEU_Hunnan_East_Gate.zip** 并解压。不要单独解压 .z01，也不要直接在 Blender 中打开压缩包。

解压后得到 **NEU_Hunnan_East_Gate.blend**（35,441,148 字节）。分卷只是为了适配网页上传大小限制，不会改变模型内容。

## 在 Blender 中打开

1. 解压后，在 Blender 中打开 .blend 文件。贴图已打包在文件内。
2. 默认场景为 **02 Symmetry inspection**，约 437 个对象，用于检查主体与对称关系；环境暂时隐藏。
3. 要查看完整可编辑环境，切换到 **01 Full gate** 场景，约 1,331 个对象。
4. 数字键盘 0 切换相机视角，F12 渲染。实体（Solid）模式适合检查几何；材质预览（Material Preview）或渲染视图用于查看材质和贴图。
5. 如果看到旧题字平面，实体模式可能把带透明通道的平面显示成整块。请用材质预览检查，避免将其误判成碑体结构或重复叠加题字。

模型由 Blender 4.3.2 制作，已在 Blender 5.2 中打开验证。

## 模型内容

- 中轴对称的校门主体、成对门柱、中央石碑与岛头
- 砖石、柱冠、凹框等可编辑几何细节
- 参考照片提取的校名笔画与落款纹理
- 简化的植栽、岗亭、灯具及可移动护栏等配景

本仓库仅发布模型和使用说明，不包含完整私人参考照片。题字及落款为参考图像衍生内容；本仓库未授予额外的统一开源许可证，使用时请自行核实相关权利。
